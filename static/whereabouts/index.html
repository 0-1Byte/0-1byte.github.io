◎ 地理一瞥 Whereabouts
使用说明

随手查一个地方

从其他 App 分享文字，或直接粘贴地名。较长的分享内容只留在本页，先挑出地名再查。

添加到主屏幕

Android：在 Chrome 打开本页，使用浏览器菜单中的“安装应用”或“添加到主屏幕”。安装后，本应用会出现在系统分享面板中；是否可分享取决于来源 App。非常长的分享可能受浏览器 URL 长度限制；如果分享失败，可复制地名后直接粘贴。

iPhone / iPad：Safari 的分享目标不支持此类网页应用。可先用 Safari 打开本页，点“分享”→“添加到主屏幕”；也可创建下面的快捷指令。

iOS 快捷指令（一次设置）

  1. 打开“快捷指令”，点“+”新建，展开快捷指令详情并开启“在共享表单中显示”；接收类型选“文本”和“URL”。
  2. 添加“URL 编码”操作，输入快捷指令收到的“输入”。
  3. 添加“URL”操作，填写 https://0-1byte.github.io/whereabouts/?text=，在等号后插入“URL 编码”的结果。
  4. 添加“打开 URL”操作并命名为“地理一瞥”。以后在其他 App 选中内容，点“分享”→“地理一瞥”。

短分享会预填并查询；长文本会留在本机供你整理。分享 URL 时请手动选择地名。很长的文本可能受系统 URL 长度限制，遇到失败时请只复制地名。不同 iOS 版本的操作名称可能略有不同。

数据与隐私

地名搜索由 Wikipedia / Wikimedia API 处理；只有你提交的查询词会发送给维基百科，分享原文和浏览记录不会上传。位置坐标取自对应百科条目，缺失时不推测。地图由 OpenStreetMap 瓦片提供；地图加载失败不影响外部地图入口。查询需要网络连接。
